Desktop Drawer 使用教程
========================

一、准备和启动
--------------
1. 本程序适用于 Windows 10 或 Windows 11。
2. 在 GitHub 页面点击 Code，再点击 Download ZIP。
3. 下载完成后解压 ZIP 文件。
4. 打开解压后的文件夹，双击 Drawer.exe 即可启动。
5. 普通用户不需要打开 src 文件夹，也不需要运行编译脚本。

如果 Windows 显示“Windows 已保护你的电脑”，请先确认文件来自可信来源，再选择“更多信息”与“仍要运行”。

开发者如果修改了 src\Drawer.cs，可以双击 build.bat 重新编译并启动程序。

首次运行会默认开启开机自动启动，方便重启电脑后继续使用。若不需要，可在“抽屉设置”中关闭。

二、打开和收起抽屉
------------------
1. 启动后，将鼠标移动到当前屏幕最左边缘，抽屉会自动滑出。
2. 鼠标离开抽屉后，抽屉会延迟片刻自动收回。
3. 抽屉已经运行时再次启动程序，会提示已有实例正在运行。

三、添加项目
------------
1. 可以把程序、快捷方式、文件或文件夹从桌面或资源管理器拖入抽屉。
2. 抽屉只保存项目路径，不会移动或删除原文件。
3. 如果拖动时 Windows 只允许“移动”，请按住 Ctrl 再拖入，以复制/引用方式添加。
4. 如果直接拖入失败，可在抽屉空白处单击右键，选择“批量添加桌面项目...”。
5. 回收站无法正常拖入时，可在右键菜单中选择“添加回收站图标”。

四、打开和排列项目
------------------
1. 单击图标可打开对应的程序、文件或文件夹。
2. 按住图标拖到空白格，可以改变它在抽屉中的位置。
3. 在空白区域按住鼠标左键拖动，可以框选多个图标。
4. 按住 Ctrl 单击图标，可以逐个增加或取消选择。
5. 选中多个图标后拖动其中一个，可以整体移动，并保留相对排列和空位。
6. 按 Esc 可取消当前选择。

五、移除和管理项目
------------------
1. 选中图标后按 Delete，可将它从抽屉中移除。
2. 也可以在图标上单击右键，选择“仅从抽屉移除”。
3. 从抽屉移除只会删除抽屉中的引用，不会删除原文件。
4. 图标右键菜单还可以在资源管理器中显示实际文件。
5. “重命名实际文件”会直接修改原文件名，使用前请确认。

六、抽屉设置
------------
1. 单击“抽屉设置”图标，或在抽屉空白处单击右键并选择“抽屉设置...”。
2. 可以调整横向间距、纵向间距、图标大小和抽屉列数。
3. 预览确认后选择保存；取消或关闭设置窗口不会保留未保存的预览。
4. 可在设置中选择是否显示 Windows 桌面图标。
5. 可启用或关闭“开机自动启动”。此选项只写入当前用户的启动项，不需要管理员权限。

七、其他右键功能
----------------
1. “隐藏桌面图标”或“显示桌面图标”：切换 Windows 桌面图标的可见状态。
2. “批量添加桌面项目...”：“拖入”不可用时的备用添加方式。
3. “添加回收站图标”：把回收站入口加入抽屉。
4. “退出”：关闭 Desktop Drawer。

八、配置和故障排查
------------------
1. 布局与外观设置保存在：%LOCALAPPDATA%\DrawerStage2
2. 如果磨砂效果不可用，请在 Windows 个性化设置中开启“透明效果”。
3. 如果编译失败，请查看构建窗口中的错误信息，并确认系统存在 .NET Framework 4.x 和 WPF 组件。
4. 如果程序运行时发生未处理错误，项目根目录可能生成 drawer-error.txt，可用它排查问题。
5. 如果程序无法正常退出，可打开任务管理器并结束 Drawer.exe。

九、删除程序
------------
1. 如果不再使用，请先在“抽屉设置”中关闭“开机自动启动”。
2. 如果隐藏过 Windows 桌面图标，请先恢复显示。
3. 在抽屉空白处单击右键，选择“退出”。
4. 删除解压后的 DesktopDrawer 文件夹即可。
5. 如需同时清除布局和外观设置，可删除 %LOCALAPPDATA%\DrawerStage2 文件夹。
